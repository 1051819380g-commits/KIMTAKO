학교운영위원회 회의 한 번에 필요한 문서 11종을 한 번의 입력으로 만듭니다. 설치나 매크로 없이 이 파일 하나면 되고, 불러온 자료와 입력한 내용은 서버로 가지 않고 이 컴퓨터의 브라우저 안에서만 처리됩니다. 입력은 이 브라우저에 자동 저장되므로 인터넷 사용 기록을 지우면 함께 사라집니다.

등록부(출석·서명) · 회의 시나리오 · 심의자료(표지·안건목록 + 취합한 안건 원문) 3종

회의 결과 — 학교장 이송

회의록 · 안건처리결과 이송 기안문 · 안건처리상황표 3종

1준비물없으면 빈칸으로 두고 나중에 채워도 됩니다

위원 명단

  • 성명 · 구분(학부모·교원·지역위원) · 직위를 적고 위원장·부위원장을 지정합니다.
  • 위원 수와 정족수는 명단에서 자동으로 셉니다. 위원이 바뀌면 1단계 명단만 고치면 됩니다.

안건 한글파일

  • 부서에서 올린 안건 파일(.hwp · .hwpx)을 2단계에 넣으면 제목·부서를 읽어 목록을 채우고 심의자료에 원문이 붙습니다.
  • 파일이 없으면 안건 제목만 손으로 적어도 됩니다.

지난 회의 엑셀

  • 전에 이 도구로 저장한 엑셀이 있으면 엑셀 불러오기로 그대로 가져옵니다.
  • 가져온 뒤 새 회의 시작(+1)을 누르면 학교·위원 정보는 남고 회의 차수만 올라갑니다.
미리 확인 회의 일시·장소, 문서번호, 근거 조례명(기본값 경상남도립학교 운영위원회 운영 조례 제19조(사립은 학교 운영위원회 규정))은 1단계에서 한 번만 넣으면 문서 11종 전부에 반영됩니다. 조례명·조문은 1단계에서 고칠 수 있습니다.

2따라 하기왼쪽 메뉴 순서대로 1 → 6단계

자료 입력 — 1·2단계

  • 학교·회의·담당자 → 위원 명단(위원장·부위원장 지정) → 안건·문서번호 순으로 채웁니다.
  • 요일 · 위원수 · 안건번호는 자동으로 채워집니다.
  • 2단계 안건 한글파일 취합에 부서별 안건 파일을 넣으면 안건 목록과 심의자료가 함께 만들어집니다.

문서 확인 — 3·4·5단계

  • 오른쪽 문서 카드를 누르면 본문에 A4 미리보기가 바로 뜹니다.
  • 빠진 입력이 있으면 미리보기 위에 표시되니, 미리보기를 보면서 1~2단계로 돌아가 채우면 됩니다.

회의 후 확정 — 5단계

  • 회의가 끝나면 출석과 안건 처리결과를 확정합니다.
  • 확정한 값이 회의록 · 안건처리상황표에 그대로 들어갑니다.

3저장·인쇄오른쪽 문서 카드 · 왼쪽 메뉴 아래 버튼

한글 저장 (.hwpx)

  • 기안문 · 공고문 · 회의록처럼 결재를 올리고 내보내는 문서에 씁니다. 한글 2014 이상에서 바로 열립니다.
  • 왼쪽 전체 한글 저장으로 단계별 · 전체 일괄 저장도 됩니다.

인쇄 · PDF

  • 미리보기 그대로 인쇄됩니다. 인쇄 창에서 대상을 PDF로 저장으로 바꾸면 PDF가 됩니다.
  • 여백 0 · 배율 기본(100%) · '배경 그래픽'을 켜면 화면과 같게 나옵니다. A4 세로 기준입니다.

엑셀 저장 — 6단계

  • Ctrl+S 또는 6단계 엑셀 저장 — 입력 전부가 한 파일에 담겨 보관 · 이동이 됩니다.
  • 다음 회의는 이 파일을 불러온 뒤 새 회의 시작(+1)만 누르면 됩니다.
4자주 묻는 것문제 해결

1.hwp 파일이 필요합니다

  • 저장된 .hwpx를 한글에서 열고 파일 → 다른 이름으로 저장에서 형식을 한글 문서(*.hwp)로 고르면 됩니다.
  • 한글 2014 이전 버전에서는 .hwpx가 열리지 않습니다. 이때는 인쇄·PDF를 쓰세요.

2안건 원문에 그림이 빠집니다

  • 안건 취합은 글과 표만 옮깁니다. 그림·도형이 있는 안건은 심의자료를 한글로 저장한 뒤 한글에서 그림을 붙이세요.

3입력한 내용이 사라졌습니다

  • 브라우저 인터넷 사용 기록 삭제나 시크릿 창에서는 자동 저장이 남지 않습니다.
  • 중요한 회의는 엑셀 저장(Ctrl+S)으로 백업해 두세요. 다른 PC에서도 그 파일로 이어서 작업합니다.

4공고는 며칠 전에 해야 하나요

  • 회의 7일 전이 원칙입니다. 화면 위 표시등이 알려 주고, 공고일·제안일·처리일은 회의일에서 자동으로 계산됩니다.

5미리보기가 한 쪽을 넘어갑니다

  • 위원이 많거나 안건이 길면 다음 쪽으로 넘어갑니다. 표는 쪽이 나뉘어도 잘리지 않으니 그대로 저장·인쇄하면 됩니다.

6회의록에 발언 내용을 넣고 싶습니다

  • 서식에 없는 발언 요지는 한글 저장 뒤 한글에서 넣는 것이 빠릅니다. 이 도구는 출석·처리결과까지만 채웁니다.
알아두기 입력을 고치면 이미 만든 문서도 다시 그려집니다 · 공고·통지는 회의 7일 전이 원칙(상단 표시등이 알려줌) · 안건 취합은 글·표만 옮기므로 그림이 있는 안건은 한글에서 확인 · 회의 후 출석과 처리결과를 확정하면 회의록에 그대로 반영 · 심의 결과의 최종 효력은 학교장 이송·시행으로 확정됩니다
